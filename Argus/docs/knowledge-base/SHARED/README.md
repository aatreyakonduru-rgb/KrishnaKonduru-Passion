# Shared context

Team-wide files every stage reads: the domain context, delivery teams
(`delivery-teams.yaml`), grooming settings (`grooming.yaml`), Learn more questions
(`learn-more.yaml`), team know-how (`team-know-how.yaml`) and the risk register
(`risk-register.yaml`). They start empty or with defaults; change them the way any
knowledge-base file is changed: Devin shows the edit and saves it after the person types
approved.
